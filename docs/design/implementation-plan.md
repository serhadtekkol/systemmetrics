# SystemMetrics Implementation Plan

> **Historical record.** This is the plan the first implementation followed; the code has since
> diverged (e.g. hover delays are 300/500 ms, not 150/300 ms; Docker discovery, swap, RAM colour
> and Docker CPU changed). For current behaviour, read the code and the design spec's §11
> Revisions (`docs/design/design-spec.md`).

**Goal:** A native macOS menu bar app (Apple Silicon, macOS 14+) that shows CPU, RAM, GPU, swap, internal/external disks and Docker usage in an iOS-style panel that opens on hover.

**Architecture:** Two targets. `MetricsKit` (framework) holds every sampler, the Docker client, the
sampling schedule, the hover state machine and the `@Observable` `MetricsEngine` — all pure logic
is split from thin system-call sources so it is unit-testable. `SystemMetrics` (app, LSUIElement)
holds AppKit glue (`NSStatusItem` + hover tracking + borderless `NSPanel`) and SwiftUI views.

**Tech Stack:** Swift 5 language mode (Swift 6.4 toolchain), SwiftUI, AppKit, Swift Charts,
IOKit, Mach host APIs, POSIX unix sockets, Swift Testing, XcodeGen.

**Spec:** `docs/design/design-spec.md`

## Global Constraints

- Platform: macOS 14.0 minimum, `arm64` only. No App Sandbox. Hardened Runtime on.
- No third-party dependencies. System frameworks only.
- No `docker` CLI, no `top`, no `powermetrics`, no `Process()` spawning of any kind.
- No private APIs. No root. Temperatures/fans are out of scope.
- Never parse localized command/sysctl text output (the user's locale prints `8192,00M`). Use structs.
- UI copy is Turkish (`veri yok`, `Docker çalışmıyor`, …). Code, identifiers, commits: English.
- Percent display format is `23%` (number then `%`), built manually, not via a locale formatter.
- Idle cost of the app: < 1% CPU, < 60 MB RAM.
- History: in-memory ring buffer, ~5 minutes, fixed size.
- Docker is read-only: only `GET` requests.
- Git identity is repo-local `serhadtekkol <4614365+serhadtekkol@users.noreply.github.com>`.
  Commit messages contain **no** `Co-Authored-By` or "Generated with" trailers. Each task is
  committed after it passes review.
- `SystemMetrics.xcodeproj` is generated by `xcodegen` and is git-ignored.

## Review Focus

1. **Counters going backwards** (CPU ticks after sleep/wake, disk byte counters after re-plug) must yield 0, never negative or huge values → tests in Task 3 and Task 6.
2. **Stale Docker socket** (file exists, daemon stopped) must resolve to `notRunning` within the 2 s timeout, not hang the UI → test in Task 7.
3. **Container disappears between list and stats** (404) must drop that container only, not the whole Docker card → test in Task 7.
4. **External exFAT/NTFS (fskit) volume with no block-driver statistics** must still show capacity, with throughput `nil` → test in Task 6.
5. **Zero/odd values** (volume total 0, swap total 0, GPU dict missing keys) must not divide by zero or crash → tests in Tasks 4, 5, 6.

```swift
import Foundation

public struct CPUSnapshot: Equatable, Sendable {
    public var total: Double
    public var perCore: [Double]
    public var efficiencyCoreCount: Int
    public init(total: Double, perCore: [Double], efficiencyCoreCount: Int) {
        self.total = total; self.perCore = perCore; self.efficiencyCoreCount = efficiencyCoreCount
    }
    public var efficiencyCores: ArraySlice<Double> { perCore.prefix(min(efficiencyCoreCount, perCore.count)) }
    public var performanceCores: ArraySlice<Double> { perCore.dropFirst(min(efficiencyCoreCount, perCore.count)) }
}

public enum MemoryPressure: Equatable, Sendable { case normal, warning, critical }

public struct MemorySnapshot: Equatable, Sendable {
    public var total: UInt64, used: UInt64, app: UInt64, wired: UInt64, compressed: UInt64
    public var pressure: MemoryPressure
    public init(total: UInt64, used: UInt64, app: UInt64, wired: UInt64, compressed: UInt64, pressure: MemoryPressure) {
        self.total = total; self.used = used; self.app = app; self.wired = wired
        self.compressed = compressed; self.pressure = pressure
    }
    public var usedFraction: Double { total == 0 ? 0 : min(1, Double(used) / Double(total)) }
}

public struct SwapSnapshot: Equatable, Sendable {
    public var total: UInt64, used: UInt64
    public init(total: UInt64, used: UInt64) { self.total = total; self.used = used }
    public var usedFraction: Double { total == 0 ? 0 : min(1, Double(used) / Double(total)) }
}

public struct GPUSnapshot: Equatable, Sendable {
    public var utilization: Double
    public var memoryInUse: UInt64
    public init(utilization: Double, memoryInUse: UInt64) { self.utilization = utilization; self.memoryInUse = memoryInUse }
}

public struct VolumeSnapshot: Equatable, Sendable, Identifiable {
    public var id: String           // mount path
    public var name: String
    public var isInternal: Bool
    public var isRoot: Bool
    public var total: UInt64
    public var available: UInt64
    public var readBytesPerSecond: Double?
    public var writeBytesPerSecond: Double?
    public init(id: String, name: String, isInternal: Bool, isRoot: Bool, total: UInt64, available: UInt64,
                readBytesPerSecond: Double? = nil, writeBytesPerSecond: Double? = nil) {
        self.id = id; self.name = name; self.isInternal = isInternal; self.isRoot = isRoot
        self.total = total; self.available = available
        self.readBytesPerSecond = readBytesPerSecond; self.writeBytesPerSecond = writeBytesPerSecond

    public var used: UInt64 { total > available ? total - available : 0 }
    public var usedFraction: Double { total == 0 ? 0 : min(1, Double(used) / Double(total)) }
}

public enum DockerState: Equatable, Sendable { case notInstalled, notRunning, running }

public struct ContainerSnapshot: Equatable, Sendable, Identifiable {
    public var id: String, name: String
    public var cpuPercent: Double?    // percent of one core, may exceed 100
    public var memory: UInt64
    public init(id: String, name: String, cpuPercent: Double?, memory: UInt64) {
        self.id = id; self.name = name; self.cpuPercent = cpuPercent; self.memory = memory
    }

public struct DockerSnapshot: Equatable, Sendable {
    public var state: DockerState
    public var containers: [ContainerSnapshot]     // sorted by memory desc
    public var diskUsage: UInt64?                  // images + volumes + build cache + container rw
```

```swift
public struct RingBuffer<Element: Sendable>: Sendable {
    public let capacity: Int
    private var storage: [Element] = []
    private var head = 0
    public init(capacity: Int) {
        precondition(capacity > 0, "RingBuffer capacity must be positive")
        self.capacity = capacity
        storage.reserveCapacity(capacity)
    }
    public var count: Int { storage.count }
    public mutating func append(_ element: Element) {
        if storage.count < capacity { storage.append(element); return }
        storage[head] = element
        head = (head + 1) % capacity
    }
    /// Oldest first.
    public var elements: [Element] {
        storage.count < capacity ? storage : Array(storage[head...] + storage[..<head])
    }
}
```

```swift
import Darwin

public enum Sysctl {
    public static func int(_ name: String) -> Int? {
        var value: Int64 = 0
        var size = MemoryLayout<Int64>.size
        guard sysctlbyname(name, &value, &size, nil, 0) == 0 else { return nil }
        // Some keys are 32-bit; sysctl writes only `size` bytes.
        return size == MemoryLayout<Int32>.size ? Int(Int32(truncatingIfNeeded: value)) : Int(value)
    }
    public static func string(_ name: String) -> String? {
        var size = 0
        guard sysctlbyname(name, nil, &size, nil, 0) == 0, size > 0 else { return nil }
        var buffer = [CChar](repeating: 0, count: size)
        guard sysctlbyname(name, &buffer, &size, nil, 0) == 0 else { return nil }
        return String(cString: buffer)
    }
    public static func value<T>(_ name: String, as type: T.Type) -> T? {
        var size = MemoryLayout<T>.size
        let pointer = UnsafeMutablePointer<T>.allocate(capacity: 1)
        defer { pointer.deallocate() }
        guard sysctlbyname(name, pointer, &size, nil, 0) == 0, size == MemoryLayout<T>.size else { return nil }
        return pointer.pointee
    }
}
```

```swift
// CPUCalculator.swift
public struct CPUTicks: Equatable, Sendable {
    public var user: UInt64, system: UInt64, idle: UInt64, nice: UInt64
    public init(user: UInt64, system: UInt64, idle: UInt64, nice: UInt64) {
        self.user = user; self.system = system; self.idle = idle; self.nice = nice
    }
}

public enum CPUCalculator {
    /// Counters can reset (sleep/wake, overflow); a negative delta counts as zero.
    static func delta(_ old: UInt64, _ new: UInt64) -> UInt64 { new >= old ? new - old : 0 }

    public static func usage(previous: [CPUTicks], current: [CPUTicks], efficiencyCoreCount: Int) -> CPUSnapshot? {
        guard !current.isEmpty, previous.count == current.count else { return nil }
        var perCore: [Double] = []
        perCore.reserveCapacity(current.count)
        var busySum: UInt64 = 0, totalSum: UInt64 = 0
        for (p, c) in zip(previous, current) {
            let busy = delta(p.user, c.user) + delta(p.system, c.system) + delta(p.nice, c.nice)
            let total = busy + delta(p.idle, c.idle)
            perCore.append(total == 0 ? 0 : Double(busy) / Double(total))
            busySum += busy; totalSum += total
        }
        return CPUSnapshot(total: totalSum == 0 ? 0 : Double(busySum) / Double(totalSum),
                           perCore: perCore, efficiencyCoreCount: efficiencyCoreCount)
    }
}
```

```swift
// CPUSampler.swift
import Darwin

public protocol CPUTickSource: AnyObject { func read() -> [CPUTicks]? }

public final class MachCPUTickSource: CPUTickSource {
    private let host = mach_host_self()
    public init() {}
    public func read() -> [CPUTicks]? {
        var cpuCount: natural_t = 0
        var info: processor_info_array_t?
        var infoCount: mach_msg_type_number_t = 0
        guard host_processor_info(host, PROCESSOR_CPU_LOAD_INFO, &cpuCount, &info, &infoCount) == KERN_SUCCESS,
              let info else { return nil }
        defer {
            vm_deallocate(mach_task_self_, vm_address_t(UInt(bitPattern: info)),
                          vm_size_t(Int(infoCount) * MemoryLayout<integer_t>.stride))
        }
        return (0..<Int(cpuCount)).map { cpu in
            let base = cpu * Int(CPU_STATE_MAX)
            func tick(_ state: Int32) -> UInt64 { UInt64(UInt32(bitPattern: info[base + Int(state)])) }
            return CPUTicks(user: tick(CPU_STATE_USER), system: tick(CPU_STATE_SYSTEM),
                            idle: tick(CPU_STATE_IDLE), nice: tick(CPU_STATE_NICE))
        }
    }
}

/// On Apple Silicon the kernel numbers efficiency cores first (verified via IODeviceTree
/// `cluster-type`), so the first `hw.perflevel1.logicalcpu` entries are E-cores.
public final class CPUSampler {
    private let source: CPUTickSource
    private let efficiencyCoreCount: Int
    private var previous: [CPUTicks]?
    public init(source: CPUTickSource = MachCPUTickSource(),
                efficiencyCoreCount: Int = Sysctl.int("hw.perflevel1.logicalcpu") ?? 0) {
        self.source = source
        self.efficiencyCoreCount = efficiencyCoreCount
        previous = source.read()
    }
    public func sample() -> CPUSnapshot? {
```

```swift
// MemoryCalculator.swift
import Darwin

public struct VMPageCounts: Equatable, Sendable {
    public var pageSize: UInt64, internal: UInt64, purgeable: UInt64, wired: UInt64, compressed: UInt64
    public init(pageSize: UInt64, internal: UInt64, purgeable: UInt64, wired: UInt64, compressed: UInt64) {
        self.pageSize = pageSize; self.internal = internal; self.purgeable = purgeable
        self.wired = wired; self.compressed = compressed
    }
}

public enum MemoryCalculator {
    /// Same breakdown as Activity Monitor: app = internal − purgeable; used = app + wired + compressed.
    public static func snapshot(pages: VMPageCounts, physical: UInt64, pressureLevel: Int) -> MemorySnapshot {
        let appPages = pages.internal > pages.purgeable ? pages.internal - pages.purgeable : 0
        let app = appPages * pages.pageSize
        let wired = pages.wired * pages.pageSize
        let compressed = pages.compressed * pages.pageSize
        let pressure: MemoryPressure = switch pressureLevel { case 4: .critical; case 2: .warning; default: .normal }
        return MemorySnapshot(total: physical, used: min(physical, app + wired + compressed),
                              app: app, wired: wired, compressed: compressed, pressure: pressure)
    }
    public static func swap(_ usage: xsw_usage) -> SwapSnapshot {
        SwapSnapshot(total: usage.xsu_total, used: usage.xsu_used)
    }
}
```

```swift
import Foundation
```

```swift
/// `PerformanceStatistics` keys are undocumented. If Apple renames them, the GPU card shows
/// "veri yok" instead of failing.
public enum GPUStatsParser {
    public static func parse(_ stats: [String: Any]) -> GPUSnapshot? {
        guard let util = (stats["Device Utilization %"] as? NSNumber)?.doubleValue else { return nil }
        let memory = (stats["In use system memory"] as? NSNumber)?.uint64Value ?? 0
        return GPUSnapshot(utilization: min(max(util / 100, 0), 1), memoryInUse: memory)
    }
}

public final class GPUSampler {
    private let read: () -> [String: Any]?
    public init(read: @escaping () -> [String: Any]? = GPUSampler.readIOAccelerator) { self.read = read }
    public func sample() -> GPUSnapshot? { read().flatMap(GPUStatsParser.parse) }

    public static func readIOAccelerator() -> [String: Any]? {
        var iterator: io_iterator_t = 0
        guard IOServiceGetMatchingServices(kIOMainPortDefault, IOServiceMatching("IOAccelerator"), &iterator) == KERN_SUCCESS
        else { return nil }
        defer { IOObjectRelease(iterator) }
        while case let service = IOIteratorNext(iterator), service != 0 {
            defer { IOObjectRelease(service) }
            if let stats = IORegistryEntryCreateCFProperty(service, "PerformanceStatistics" as CFString,
                                                           kCFAllocatorDefault, 0)?.takeRetainedValue() as? [String: Any] {
                return stats
            }
        }
        return nil
    }
}
```

```swift
// DiskCalculator.swift
import Foundation

public struct DiskIOCounters: Equatable, Sendable {
    public var read: UInt64, write: UInt64
    public init(read: UInt64, write: UInt64) { self.read = read; self.write = write }
}

public struct VolumeInfo: Equatable, Sendable {
    public var path: String, name: String, isInternal: Bool, isRoot: Bool
    public var total: UInt64, available: UInt64, bsdName: String?
    public init(path: String, name: String, isInternal: Bool, isRoot: Bool, total: UInt64, available: UInt64, bsdName: String?) {
        self.path = path; self.name = name; self.isInternal = isInternal; self.isRoot = isRoot
        self.total = total; self.available = available; self.bsdName = bsdName
    }
}

public enum DiskCalculator {
    public static func rate(previous: DiskIOCounters, current: DiskIOCounters, elapsed: TimeInterval) -> (read: Double, write: Double)? {
        guard elapsed > 0 else { return nil }
        let r = current.read >= previous.read ? current.read - previous.read : 0
        let w = current.write >= previous.write ? current.write - previous.write : 0
        return (Double(r) / elapsed, Double(w) / elapsed)
    }
    public static func ordered(_ volumes: [VolumeSnapshot]) -> [VolumeSnapshot] {
        volumes.sorted { a, b in
            if a.isRoot != b.isRoot { return a.isRoot }
            if a.isInternal != b.isInternal { return a.isInternal }
            return a.name.localizedStandardCompare(b.name) == .orderedAscending
        }
    }
}
```

```swift
// DiskSampler.swift
import Foundation
import IOKit

public protocol VolumeSource { func volumes() -> [VolumeInfo] }
public protocol DiskIOSource { func counters(bsdName: String) -> DiskIOCounters? }

public struct FileManagerVolumeSource: VolumeSource {
    private static let keys: [URLResourceKey] = [.volumeNameKey, .volumeIsInternalKey, .volumeIsRootFileSystemKey,
        .volumeIsBrowsableKey, .volumeTotalCapacityKey, .volumeAvailableCapacityKey,
        .volumeAvailableCapacityForImportantUsageKey]
    public init() {}
    public func volumes() -> [VolumeInfo] {
        let urls = FileManager.default.mountedVolumeURLs(includingResourceValuesForKeys: Self.keys,
                                                         options: [.skipHiddenVolumes]) ?? []
        return urls.compactMap { url in
            guard let v = try? url.resourceValues(forKeys: Set(Self.keys)), v.volumeIsBrowsable == true else { return nil }
            let path = url.path
            let isRoot = v.volumeIsRootFileSystem == true
            guard isRoot || path.hasPrefix("/Volumes/") else { return nil }
            let total = UInt64(max(0, v.volumeTotalCapacity ?? 0))
            let important = v.volumeAvailableCapacityForImportantUsage.map { UInt64(max(0, $0)) }
            let available = important ?? UInt64(max(0, v.volumeAvailableCapacity ?? 0))
            return VolumeInfo(path: path, name: v.volumeName ?? url.lastPathComponent,
                              isInternal: v.volumeIsInternal ?? false, isRoot: isRoot,
                              total: total, available: min(available, total), bsdName: Self.bsdName(path))
        }
    }
    static func bsdName(_ path: String) -> String? {
        var fs = statfs()
        guard statfs(path, &fs) == 0 else { return nil }
        let from = withUnsafeBytes(of: &fs.f_mntfromname) { String(cString: $0.bindMemory(to: CChar.self).baseAddress!) }
        return from.hasPrefix("/dev/") ? String(from.dropFirst(5)) : nil
    }
}

/// Walks up the IOService plane from the volume's IOMedia (through APFS container and
/// partition scheme) to the IOBlockStorageDriver that owns the byte counters.
public struct IOKitDiskIOSource: DiskIOSource {
    public init() {}
    public func counters(bsdName: String) -> DiskIOCounters? {
        guard let matching = IOBSDNameMatching(kIOMainPortDefault, 0, bsdName) else { return nil }
        var entry = IOServiceGetMatchingService(kIOMainPortDefault, matching)
        guard entry != 0 else { return nil }
        for _ in 0..<24 {
            if IOObjectConformsTo(entry, "IOBlockStorageDriver") != 0 {
                defer { IOObjectRelease(entry) }
                guard let stats = IORegistryEntryCreateCFProperty(entry, "Statistics" as CFString, kCFAllocatorDefault, 0)?
                    .takeRetainedValue() as? [String: Any],
                      let r = (stats["Bytes (Read)"] as? NSNumber)?.uint64Value,
                      let w = (stats["Bytes (Write)"] as? NSNumber)?.uint64Value else { return nil }
                return DiskIOCounters(read: r, write: w)
            }
            var parent: io_registry_entry_t = 0
            let kr = IORegistryEntryGetParentEntry(entry, kIOServicePlane, &parent)
            IOObjectRelease(entry)
            guard kr == KERN_SUCCESS else { return nil }
            entry = parent
        }
        IOObjectRelease(entry)
        return nil
    }
}

public final class DiskSampler {
    private let volumeSource: VolumeSource
    private let io: DiskIOSource
    private var previous: [String: (counters: DiskIOCounters, at: Date)] = [:]
    public init(volumes: VolumeSource = FileManagerVolumeSource(), io: DiskIOSource = IOKitDiskIOSource()) {
        self.volumeSource = volumes; self.io = io
    }
    public func sample(now: Date) -> [VolumeSnapshot] {
        var next: [String: (counters: DiskIOCounters, at: Date)] = [:]
        let snapshots = volumeSource.volumes().map { info -> VolumeSnapshot in
            var s = VolumeSnapshot(id: info.path, name: info.name, isInternal: info.isInternal, isRoot: info.isRoot,
                                   total: info.total, available: info.available)
            if let bsd = info.bsdName, let current = io.counters(bsdName: bsd) {
                if let prev = previous[info.path],
                   let r = DiskCalculator.rate(previous: prev.counters, current: current, elapsed: now.timeIntervalSince(prev.at)) {
                    s.readBytesPerSecond = r.read; s.writeBytesPerSecond = r.write
                }
                next[info.path] = (current, now)
            }
            return s
        }
        previous = next      // unmounted volumes drop out here
        return DiskCalculator.ordered(snapshots)
    }
}
```

```swift
import Darwin
import Foundation

public struct HTTPResponse: Equatable, Sendable {
    public var status: Int, body: Data
    public init(status: Int, body: Data) { self.status = status; self.body = body }
}

public enum UnixSocketError: Error, Equatable {
    case socketPathTooLong, socketFailed(Int32), connectFailed(Int32), writeFailed(Int32)
    case readFailed(Int32), timeout, responseTooLarge, malformedResponse
}

public protocol HTTPTransport: AnyObject { func get(_ path: String) throws -> HTTPResponse }

/// Minimal HTTP/1.0 GET over a unix domain socket. HTTP/1.0 makes the server close the
/// connection after the body and avoids chunked encoding, so reading to EOF is the whole parser.
public final class UnixSocketHTTPClient: HTTPTransport {
    public let socketPath: String
    public let timeout: TimeInterval
    private static let maxResponseBytes = 16 * 1024 * 1024

    public init(socketPath: String, timeout: TimeInterval = 2) { self.socketPath = socketPath; self.timeout = timeout }

    public func get(_ path: String) throws -> HTTPResponse {
        let fd = socket(AF_UNIX, SOCK_STREAM, 0)
        guard fd >= 0 else { throw UnixSocketError.socketFailed(errno) }
        defer { close(fd) }

        var one: Int32 = 1
        setsockopt(fd, SOL_SOCKET, SO_NOSIGPIPE, &one, socklen_t(MemoryLayout<Int32>.size))
        var tv = timeval(tv_sec: Int(timeout), tv_usec: Int32((timeout - timeout.rounded(.down)) * 1_000_000))
        setsockopt(fd, SOL_SOCKET, SO_RCVTIMEO, &tv, socklen_t(MemoryLayout<timeval>.size))
        setsockopt(fd, SOL_SOCKET, SO_SNDTIMEO, &tv, socklen_t(MemoryLayout<timeval>.size))

        var addr = sockaddr_un()
        addr.sun_family = sa_family_t(AF_UNIX)
        let pathBytes = Array(socketPath.utf8) + [0]
        guard pathBytes.count <= MemoryLayout.size(ofValue: addr.sun_path) else { throw UnixSocketError.socketPathTooLong }
        withUnsafeMutableBytes(of: &addr.sun_path) { $0.copyBytes(from: pathBytes) }
        addr.sun_len = UInt8(MemoryLayout<sockaddr_un>.size)
        let connected = withUnsafePointer(to: &addr) {
            $0.withMemoryRebound(to: sockaddr.self, capacity: 1) { connect(fd, $0, socklen_t(MemoryLayout<sockaddr_un>.size)) }
        }
        guard connected == 0 else { throw UnixSocketError.connectFailed(errno) }

        let request = Array("GET \(path) HTTP/1.0\r\nHost: docker\r\n\r\n".utf8)
        var sent = 0
        while sent < request.count {
            let n = request[sent...].withUnsafeBytes { write(fd, $0.baseAddress, $0.count) }
            if n < 0 { if errno == EINTR { continue }; throw errno == EAGAIN ? UnixSocketError.timeout : UnixSocketError.writeFailed(errno) }
            sent += n
        }

        var response = Data()
        var buffer = [UInt8](repeating: 0, count: 64 * 1024)
        while true {
            let n = read(fd, &buffer, buffer.count)
            if n > 0 {
                response.append(buffer, count: n)
                if response.count > Self.maxResponseBytes { throw UnixSocketError.responseTooLarge }
            } else if n == 0 {
                break
            } else if errno == EINTR {
                continue
            } else {
                throw (errno == EAGAIN || errno == EWOULDBLOCK) ? UnixSocketError.timeout : UnixSocketError.readFailed(errno)
            }
        }
        return try Self.parse(response)
    }

    public static func parse(_ data: Data) throws -> HTTPResponse {
        let separator = Data("\r\n\r\n".utf8)
        guard let headerEnd = data.range(of: separator) else { throw UnixSocketError.malformedResponse }
        let head = String(decoding: data[..<headerEnd.lowerBound], as: UTF8.self)
        let statusLine = head.split(separator: "\r\n", maxSplits: 1).first ?? ""
        let parts = statusLine.split(separator: " ")
        guard parts.count >= 2, parts[0].hasPrefix("HTTP/"), let status = Int(parts[1]) else {
            throw UnixSocketError.malformedResponse
        }
        return HTTPResponse(status: status, body: Data(data[headerEnd.upperBound...]))
    }
}
```

```swift
struct DockerCPUSample: Equatable, Sendable {
    var container: UInt64, system: UInt64, onlineCPUs: Int
}

enum DockerCalculator {
    /// Same formula as `docker stats`: Δcontainer / Δsystem × online CPUs × 100.
    static func cpuPercent(previous: DockerCPUSample, current: DockerCPUSample) -> Double? {
        guard current.system > previous.system, current.container >= previous.container else { return nil }
        let c = Double(current.container - previous.container), s = Double(current.system - previous.system)
        return c / s * Double(max(1, current.onlineCPUs)) * 100
    }
    static func cpuSample(_ stats: DockerStats) -> DockerCPUSample? {
        guard let system = stats.cpu_stats.system_cpu_usage else { return nil }
        return DockerCPUSample(container: stats.cpu_stats.cpu_usage.total_usage, system: system,
                               onlineCPUs: stats.cpu_stats.online_cpus ?? 1)
    }
    /// `docker stats` subtracts page cache: cgroup v2 `inactive_file`, v1 `total_inactive_file`.
    static func memoryUsage(_ stats: DockerStats) -> UInt64 {
        let usage = stats.memory_stats.usage ?? 0
        let cache = stats.memory_stats.stats?["inactive_file"] ?? stats.memory_stats.stats?["total_inactive_file"] ?? 0
        return usage > cache ? usage - cache : 0
    }
    static func diskUsage(_ df: DockerDiskUsage) -> UInt64 {
        func pos(_ v: Int64?) -> UInt64 { UInt64(max(0, v ?? 0)) }
        return pos(df.LayersSize)
            + (df.Volumes ?? []).map { pos($0.UsageData?.Size) }.reduce(0, +)
            + (df.BuildCache ?? []).map { pos($0.Size) }.reduce(0, +)
            + (df.Containers ?? []).map { pos($0.SizeRw) }.reduce(0, +)
    }
}
```

```swift
import Foundation

/// Blocking socket I/O runs on a private serial queue, never on the main thread or the
/// Swift cooperative pool. All mutable state is confined to that queue.
public final class DockerSampler: @unchecked Sendable {
    public static let reprobeInterval: TimeInterval = 10
    public static let diskUsageInterval: TimeInterval = 30
    public static let maxContainers = 30

    private let queue = DispatchQueue(label: "com.serhadtekkol.SystemMetrics.docker", qos: .utility)
    private let transportFactory: () -> HTTPTransport?
    private let isInstalled: () -> Bool
    private var transport: HTTPTransport?
    private var last: DockerSnapshot?
    private var lastProbe: Date?
    private var lastDiskUsage: (value: UInt64, at: Date)?
    private var previousCPU: [String: DockerCPUSample] = [:]

    public init(transportFactory: @escaping () -> HTTPTransport? = {
                    DockerLocator.socketPath().map { UnixSocketHTTPClient(socketPath: $0, timeout: 2) } },
                isInstalled: @escaping () -> Bool = { DockerLocator.isInstalled() }) {
        self.transportFactory = transportFactory
        self.isInstalled = isInstalled
    }

    public func sample(now: Date) async -> DockerSnapshot {
        await withCheckedContinuation { continuation in
            queue.async { continuation.resume(returning: self.sampleSync(now: now)) }
        }
    }

    private func sampleSync(now: Date) -> DockerSnapshot {
        if let last, last.state != .running, let lastProbe, now.timeIntervalSince(lastProbe) < Self.reprobeInterval {
            return last
        }
        let result = probeAndSample(now: now)
        if result.state != .running { lastProbe = now; transport = nil; previousCPU = [:] }
        last = result
        return result
    }

    private func probeAndSample(now: Date) -> DockerSnapshot {
        if transport == nil { transport = transportFactory() }
        guard let transport else { return DockerSnapshot(state: isInstalled() ? .notRunning : .notInstalled) }
        guard let ping = try? transport.get("/_ping"), ping.status == 200 else { return DockerSnapshot(state: .notRunning) }
        guard let list = try? transport.get("/containers/json"), list.status == 200,
              let summaries = try? JSONDecoder().decode([DockerContainerSummary].self, from: list.body) else {
            return DockerSnapshot(state: .notRunning)
        }
        let decoder = JSONDecoder()
        var nextCPU: [String: DockerCPUSample] = [:]
        var containers: [ContainerSnapshot] = []
        for summary in summaries.prefix(Self.maxContainers) {
            guard let r = try? transport.get("/containers/\(summary.id)/stats?stream=false&one-shot=true"), r.status == 200,
                  let stats = try? decoder.decode(DockerStats.self, from: r.body) else { continue }  // vanished: skip
            let cpu = DockerCalculator.cpuSample(stats)
            if let cpu { nextCPU[summary.id] = cpu }
            let percent = zip2(previousCPU[summary.id], cpu).flatMap { DockerCalculator.cpuPercent(previous: $0, current: $1) }
            containers.append(ContainerSnapshot(id: summary.id, name: summary.displayName, cpuPercent: percent,
                                                memory: DockerCalculator.memoryUsage(stats)))
        }
        previousCPU = nextCPU
        if lastDiskUsage.map({ now.timeIntervalSince($0.at) >= Self.diskUsageInterval }) ?? true,
           let r = try? transport.get("/system/df"), r.status == 200,
           let df = try? decoder.decode(DockerDiskUsage.self, from: r.body) {
            lastDiskUsage = (DockerCalculator.diskUsage(df), now)
        }
        return DockerSnapshot(state: .running, containers: containers.sorted { $0.memory > $1.memory },
                              diskUsage: lastDiskUsage?.value)
    }

    private func zip2<A, B>(_ a: A?, _ b: B?) -> (A, B)? { if let a, let b { return (a, b) }; return nil }
}
```

```swift
@Observable
public final class MetricsEngine {
    public private(set) var snapshot: SystemSnapshot = .empty
    public private(set) var history: History
    public let hostInfo: HostInfo
    public var refreshInterval: TimeInterval {
        didSet {
            guard refreshInterval != oldValue else { return }
            history = History(capacity: History.capacity(forInterval: refreshInterval))
            if timer != nil { start() }
        }
    }
    public var isPanelOpen = false {
        didSet { if isPanelOpen && !oldValue { tick(now: Date()) } }
    }

    @ObservationIgnored private let samplers: Samplers
    @ObservationIgnored private var schedule = SamplingSchedule()
    @ObservationIgnored private var timer: Timer?
    @ObservationIgnored private var dockerTask: Task<Void, Never>?
    @ObservationIgnored private var mountObservers: [NSObjectProtocol] = []

    public init(refreshInterval: TimeInterval = 2, samplers: Samplers = .live(), hostInfo: HostInfo = .current()) {
        self.refreshInterval = refreshInterval
        self.samplers = samplers
        self.hostInfo = hostInfo
        history = History(capacity: History.capacity(forInterval: refreshInterval))
    }

    public func start() {
        timer?.invalidate()
        let t = Timer(timeInterval: refreshInterval, repeats: true) { [weak self] _ in
            MainActor.assumeIsolated { self?.tick(now: Date()) }
        }
        t.tolerance = refreshInterval * 0.2       // let the system coalesce wakeups
        RunLoop.main.add(t, forMode: .common)
        timer = t
        if mountObservers.isEmpty {
            let center = NSWorkspace.shared.notificationCenter
            for name in [NSWorkspace.didMountNotification, NSWorkspace.didUnmountNotification] {
                mountObservers.append(center.addObserver(forName: name, object: nil, queue: .main) { [weak self] _ in
                    MainActor.assumeIsolated { if self?.isPanelOpen == true { self?.tick(now: Date()) } }
                })
            }
        }
        tick(now: Date())
    }

        timer?.invalidate(); timer = nil
        mountObservers.forEach(NSWorkspace.shared.notificationCenter.removeObserver)
        mountObservers = []
    }
```

```swift
public struct HoverStateMachine: Sendable {
    public enum State: Equatable, Sendable { case closed, opening, open, closing, pinned }
    public enum Event: Equatable, Sendable {
        case itemEntered, itemExited, panelEntered, panelExited, openTimerFired, closeTimerFired, clicked, escape
    }
    public enum Effect: Equatable, Sendable {
        case startOpenTimer(Double), startCloseTimer(Double), cancelTimers, showPanel(pinned: Bool), hidePanel
    }
    public static let openDelay = 0.15
    public static let closeDelay = 0.3

    public private(set) var state: State = .closed
    private var inItem = false, inPanel = false
    public init() {}

    public mutating func handle(_ event: Event) -> [Effect] {
        switch event {
        case .itemEntered: inItem = true
        case .itemExited: inItem = false
        case .panelEntered: inPanel = true
        case .panelExited: inPanel = false
        default: break
        }
        switch (state, event) {
        case (.pinned, .clicked), (_, .escape) where state != .closed:
            state = .closed; return [.cancelTimers, .hidePanel]
        case (.pinned, _):
            return []
        case (_, .clicked):
            state = .pinned; return [.cancelTimers, .showPanel(pinned: true)]
        case (.closed, .itemEntered):
            state = .opening; return [.startOpenTimer(Self.openDelay)]
        case (.opening, .itemExited):
            state = .closed; return [.cancelTimers]
        case (.opening, .openTimerFired):
            state = .open; return [.showPanel(pinned: false)]
        case (.open, .itemExited), (.open, .panelExited):
            guard !inItem && !inPanel else { return [] }
            state = .closing; return [.startCloseTimer(Self.closeDelay)]
        case (.closing, .itemEntered), (.closing, .panelEntered):
            state = .open; return [.cancelTimers]
        case (.closing, .closeTimerFired):
            state = .closed; return [.hidePanel]
        default:
            return []
        }
    }
}
```

```swift
import AppKit
import SwiftUI
import MetricsKit

@MainActor
final class AppDelegate: NSObject, NSApplicationDelegate {
    private var engine: MetricsEngine!
    private var settings: AppSettings!
    private var statusItem: StatusItemController!
    private var panel: PanelController!
    private var machine = HoverStateMachine()
    private var openTimer: Timer?
    private var closeTimer: Timer?
    private var settingsWindow: NSWindow?

    func applicationDidFinishLaunching(_ notification: Notification) {
        settings = AppSettings()
        engine = MetricsEngine(refreshInterval: settings.refreshInterval)
        statusItem = StatusItemController()
        panel = PanelController(rootView: PanelView(engine: engine, settings: settings,
                                                    onOpenSettings: { [weak self] in self?.openSettings() },
                                                    onQuit: { NSApp.terminate(nil) }))
        statusItem.onEvent = { [weak self] in self?.handle($0) }
        panel.onEvent = { [weak self] in self?.handle($0) }
        observe()
        engine.start()
    }

    private func handle(_ event: HoverStateMachine.Event) {
        for effect in machine.handle(event) {
            switch effect {
            case .startOpenTimer(let delay):
                openTimer = .scheduledTimer(withTimeInterval: delay, repeats: false) { [weak self] _ in
                    MainActor.assumeIsolated { self?.handle(.openTimerFired) }
                }
            case .startCloseTimer(let delay):
                closeTimer = .scheduledTimer(withTimeInterval: delay, repeats: false) { [weak self] _ in
                    MainActor.assumeIsolated { self?.handle(.closeTimerFired) }
                }
            case .cancelTimers:
                openTimer?.invalidate(); closeTimer?.invalidate()
            case .showPanel(let pinned):
                guard let anchor = statusItem.buttonScreenFrame else { continue }
                engine.isPanelOpen = true
                panel.show(below: anchor, pinned: pinned)
            case .hidePanel:
                panel.hide()
                engine.isPanelOpen = false
            }
        }
    }

    /// Re-arms itself after each change: label + panel size follow the latest snapshot and settings.
    private func observe() {
        withObservationTracking {
            _ = engine.snapshot
            _ = settings.menuBarContent
            _ = settings.refreshInterval
        } onChange: { [weak self] in
            Task { @MainActor in self?.render(); self?.observe() }
        }
        render()
    }

    private func render() {
        statusItem.update(snapshot: engine.snapshot, content: settings.menuBarContent)
        if engine.refreshInterval != settings.refreshInterval { engine.refreshInterval = settings.refreshInterval }
        if panel.isVisible, let anchor = statusItem.buttonScreenFrame { panel.reposition(below: anchor) }
    }

    private func openSettings() {
        handle(.escape)
        if settingsWindow == nil {
            let window = NSWindow(contentViewController: NSHostingController(rootView: SettingsView(settings: settings)))
            window.title = "SystemMetrics Ayarları"
            window.styleMask = [.titled, .closable]
            window.isReleasedWhenClosed = false
            window.center()
            settingsWindow = window
        }
        NSApp.activate()
        settingsWindow?.makeKeyAndOrderFront(nil)
    }
}
```
